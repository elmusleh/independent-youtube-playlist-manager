# Security Policy

## Supported Versions

We provide security updates for the latest released version.

| Version | Supported          |
| ------- | ------------------ |
| 2.12.x  | :white_check_mark: |
| < 2.12  | :x:                |

## Reporting a Vulnerability

**Do not open a public GitHub issue for security vulnerabilities.**

If you discover a security-related bug (such as issues with OAuth2 tokens, data leakage, or unauthorized API access), please report it privately.

- **Email**: elmusleh.mohammad@gmail.com
- **Response Time**: Please allow 48-72 hours for an initial acknowledgment.

### Our Process
1. **Acknowledgment**: We will confirm receipt of your report.
2. **Investigation**: We will verify the vulnerability and determine its impact.
3. **Fix**: We will work on a patch for the supported versions.
4. **Disclosure**: Once a fix is released, we can coordinate a public announcement to credit your discovery.

We appreciate your help in keeping this project secure!
