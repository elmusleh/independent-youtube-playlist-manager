# AMO Screenshots

AMO requires **at least one screenshot** for a listed add-on. A strong set of screenshots significantly improves discoverability and user trust.

---

## Required Specs

| Property | Requirement |
|----------|-------------|
| **Format** | PNG or JPG |
| **Recommended sizes** | 1280×800 or 640×400 |
| **Aspect ratio** | ~16:10 |
| **Max file size** | 4 MB per image |
| **Min count** | 1 |
| **Recommended count** | 4–5 |

---

## Recommended Screenshots

Capture these views in Firefox with the extension installed:

1. **Main Editor View**
   - Open the Playlist Editor (`about:addons` → Options, or click the toolbar icon)
   - Show a playlist populated with several videos
   - Include thumbnails and drag handles if visible

2. **Saved Playlists Grid**
   - Navigate to the Saved Playlists section
   - Show multiple playlist cards with titles and video counts

3. **Quick Add Popup**
   - Visit any `youtube.com/watch?v=...` page
   - Click the extension toolbar icon
   - Capture the popup with "Add to Favorite / Latest / Saved Playlist" buttons

4. **Settings Page**
   - Open Settings within the editor
   - Show theme toggle (light/dark/device), per-page count, cache duration, etc.

5. **Dark Mode View**
   - Switch the editor to Dark theme
   - Capture the main editor or saved playlists grid in dark mode

---

## Naming Convention

Save files as:

```
screenshot-01-editor.png
screenshot-02-saved-playlists.png
screenshot-03-quick-add-popup.png
screenshot-04-settings.png
screenshot-05-dark-mode.png
```

Place the final files in this `docs/amo-submission/screenshots/` directory before uploading to AMO. The capture utility also stores supplemental editor views here using the `screenshot-06-*` naming range; submit only the strongest 4–5 images to AMO.
