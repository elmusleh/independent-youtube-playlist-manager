# AMO and Store Assets

This directory contains source files and reusable assets for browser-store listings and AMO submissions.

| Item | Purpose |
|------|---------|
| `*.html` | Editable promotional layouts |
| `_shared.css` | Shared styles for promotional layouts |
| `*.png` | Rendered promotional artwork |

The capture tool is in `../tools/capture.js`. Final AMO screenshots belong in `../screenshots/`. The promotional artwork stays here because it is source material and may be reused for Chrome Web Store, Firefox AMO, or release announcements.
