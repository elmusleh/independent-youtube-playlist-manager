1. **Firefox SpiderMonkey `window` getter crash** — Fixed strict-mode `TypeError: setting getter-only property "window"` in `sync-engine-registration.ts` that crashed the background engine on load. Added guard and skipped duplicate listener registration when imported in editor/popup contexts.

3. **Firefox MV3 user-gesture permission** — `browser.permissions.request()` now invoked synchronously on click before any `await`, so the native relay permission dialog displays. Added 1-click "Allow relay access" button + live status badge.

4. **Shadow store binding** — `ensureShadowBinding(space, relayUrl)` resets IndexedDB shadows on key/relay changes, preventing legacy `mawqiei.net` shadows from suppressing initial push to `pfydngsbcmuhsqqjbcte`.

5. **Background settings sync** — Extracted `adapter-storage-io.ts` to read/write syncable settings directly from `storage.local` + `storage.sync` (filtered by `SYNCABLE_SETTING_KEYS`), unified merge allowlist, fixed 3-way settings merge.

6. **Playlist `string[]` video array merge** — Native 3-way merge for video ID arrays (no more character-indexed object corruption), ISO `updatedAt` parsing, single-sided title edits preserved.

7. **Sync Safety Backups** — Automatic pre-sync rolling local snapshots (`yph_sync_safety_backups`), 1-click JSON export/restore, anti-mass-wipe guard (`>= 3` playlists → `0` requires explicit opt-in).

8. **Sync Status Report Modal** — Immediate `isSyncing = true` on manual sync, dismissible `SyncReportModal` with per-category counts, duration, relay host, connected devices, local totals.

9. **Per-backend Test Connection** — Moved from `SyncKeyCard` into `RelayCard` (IYPM hosted) and `SupabaseCard` (BYO) with inline diagnostics, 404/PGRST202 missing-schema detection, 4-emoji + 4-word key fingerprint.
